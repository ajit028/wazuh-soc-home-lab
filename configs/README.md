# Configuration Files

This folder contains sample configuration files used in the Wazuh SOC Home Lab.

## Files

- ossec.conf.sample
  - Sample Wazuh Agent configuration.

- local_rules.xml.sample
  - Sample custom detection rules.

- sysmonconfig.xml.sample
  - Sample Sysmon configuration used for endpoint monitoring.

> Note:
> Sensitive information such as IP addresses, agent keys, usernames, and environment-specific settings has been removed before publishing this repository.
